# guangzhou-inner-ring-road-drive · 广州内环路驾驶

A web game for driving at Guangzhou Inner Ring Road — 一个在浏览器里驾驶**广州内环路**的 3D 驾驶模拟游戏。
道路、匝道、高架层次、沿线街道与建筑均由 **OpenStreetMap 真实数据** 生成，**A线（逆时针）** 与
**B线（顺时针）** 全线约 23.4 km 都可以驾驶，包括全部出入口匝道。

**[▶ 在线试玩](https://h82258652.github.io/guangzhou-inner-ring-road-drive/)**（GitHub Pages，`main` 分支更新后自动部署）

## 特性

- **真实线形**：从 OSM 追踪出内环路两条闭合主线及 70+ 条出入口匝道（含**左侧出入口**、双层高架段、
  跨珠江的人民桥与江湾大桥），按 OSM `layer` 推算桥面高度并求解坡度（主线 ≤5%，匝道 ≤8%）与上下层净空。
- **可驾驶匝道**：从入口匝道加速车道汇入主线，从出口匝道减速车道驶离；驶到匝道尽头即“下内环”，
  可结束行程或就近换上 A线/B线。
- **道路细节**：车道虚线（6 m/9 m）、左侧黄色边线、导流线与防撞垫、出口前的导向箭头、
  黄色路面限速数字（主线 60、匝道 40/30）、新泽西防撞墙、箱梁与桥墩
  （双层段为门式墩）、单臂 LED 路灯（夜间路面光斑）、簕杜鹃花槽、居民楼旁的隔音屏、伸缩缝（“咯噔”声）。
- **交通标志**：按 GB 5768.2-2022 绘制的绿底白字指路标志（出口编号与去向按维基百科出口表：
  A1–A19（A5 如意坊出口为在建放射线预留、尚未开通）、B1–B19，B1 位于西场、B2 为广园西路；
  江湾大桥北端往大沙头路的下桥匝道无编号；中英文地名、1 km / 500 m 预告），
  “内环路 A线/B线”确认标志、限速 60/40/30、测速提示、可变情报板。
- **交通流**：IDM 跟驰 + MOBIL 换道的 AI 车流（轿车、出租车、SUV、MPV、公交……挂“粤A”蓝牌/绿牌），
  在两条线上双向行驶；约四分之一的司机会在任一出口驶离，经减速车道驶入匝道直到地面道路；
  入口匝道的车辆在加速车道上择机汇入（找不到空档就在车道尽头等待），并且会算好时机，
  让你驶过入口时能看到匝道车流汇入；变道前先打转向灯（少数司机不打灯），被撞后开启双闪；
  车流可选无 / 稀疏 / 正常 / 早晚高峰（走走停停）。
- **城市环境**：约 5 万栋建筑（OSM 轮廓 + 程序化补全，广州式瓷砖外墙、防盗网与空调外机）、
  地面街道、珠江水面、公园绿地与榕树、广州站铁路、白云山/越秀山地形，以及广州塔（夜间彩灯）、
  珠江新城双塔、中信广场、镇海楼、海印大桥、海珠桥等地标。
- **时间与天气**：清晨/白天/黄昏/夜晚，晴/阴/雨（湿滑路面与抓地力下降）。
- **玩法**：自由驾驶、行程模式（指定出口 + 文字导航）、计圈挑战；违章记录（定点/区间测速超速、
  驶入导流线、未打灯变道、碰撞护栏、快速路倒车）与驾驶评分。
- **竞速模式**：在 A线或 B线上与 3 / 5 / 7 名 AI 车手比赛（冲刺 5 km、半圈或一圈），对手水平分新手 / 老司机 / 车神。
  比赛中**无视一切交通法规**：不限速、测速不拍照、不记任何违章；所有赛车换上竞速调校（更大功率、更强抓地与制动）。
  倒数 3-2-1 后从最后一排发车，车流照常行驶；AI 车手按弯道曲率决定入弯速度、选择最空的车道超车、
  避开即将消失的车道和汇入的车辆。HUD 显示名次、用时、剩余距离与实时排名，小地图上有对手位置；
  驶离主线或掉头后按 `R` 回到赛道。
- **防穿模**：指路标志龙门架跨过并行的匝道/对向车道、立柱落在外侧护栏上；双层高架下层改用悬臂式标志，
  被上层桥面挡住的路灯不再穿出桥面；桥墩避开下方道路（必要时改为门式墩）；单柱标志避开导流区；
  行道树不再长在马路中间，树冠不再伸进桥面；不可驾驶的高架与街道不再与内环路路面重叠。
  这些都由 `tests/clearance.test.ts` 对照路网逐一校验。
- **体验**：追尾/远景/引擎盖/驾驶舱（左舵）/电影视角，小地图与全图，WebAudio 合成的发动机、风噪、
  胎噪、喇叭与雨声；支持键盘、手柄与触屏。

## 运行

需要 Node.js 20.19+ / 22.12+。

```bash
npm install
npm run dev        # 打开 http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm test           # 单元测试 + 自动驾驶整圈仿真 + 无头车流 / 竞速仿真
npm run e2e        # Playwright 浏览器冒烟测试（加载城市、开始驾驶并加速；开始一场竞速）
```

`npm run e2e` 默认使用 Playwright 自带的 Chromium（先执行 `npx playwright install chromium`）；
也可以设置 `PW_CHANNEL=msedge`（或 `chrome`）直接使用本机已安装的浏览器。

## 部署（GitHub Pages）

推送到 `main` 后，[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) 会执行 `npm ci` 与
`npm run build`，并把 `dist/` 发布到 GitHub Pages；也可以在仓库的 Actions 页面手动运行这个工作流。
构建产物使用相对路径（`vite.config.ts` 中的 `base: './'`），部署在 `https://<用户名>.github.io/<仓库名>/`
这样的子路径下无需修改配置。Fork 后，在仓库 **Settings → Pages** 中把 **Source** 设为 **GitHub Actions** 即可启用。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` | 油门 |
| `S` / `↓` | 刹车（停稳后长按倒车） |
| `A` `D` / `←` `→` | 转向 |
| `Space` | 手刹 |
| `Q` / `E` | 左 / 右转向灯 |
| `X` | 危险报警闪光灯（双闪） |
| `C` | 切换视角 · `V` 回头看 |
| `L` | 大灯 · `B` 喇叭 |
| `M` | 全图 · `H` 隐藏 HUD |
| `R` | 回到车道（竞速模式中驶离赛道或掉头后回到赛道） |
| `Esc` / `P` | 暂停 |

手柄：RT 油门、LT 刹车、左摇杆转向、Y 切换视角、Start 暂停、十字键左/右转向灯、十字键下双闪。

## 数据管线

生成好的数据已提交在 `public/data/`，运行游戏不需要联网。如需重新生成：

```bash
npm run data:fetch   # 通过 Overpass API 下载 OSM 数据到 scripts/.cache（已忽略）
npm run data:build   # 生成 public/data/network.json 与 city.json
npm run assets       # 下载 CC0 纹理（Poly Haven）到 public/assets/textures
```

管线主要步骤（`scripts/lib/`）：

1. `network.ts`：在有向图中追踪两条闭合环（面积符号判定 A线逆时针 / B线顺时针），以广州站为里程 0；
   发现匝道并在节点处切分路段；平滑与等距采样；把匝道贴靠主线外缘生成渐变段，计算导流区（开放侧）。
2. `elevation.ts`：按 layer 目标高度迭代求解，约束最大纵坡、匝道与主线同层衔接、上下层 ≥7 m 净空。
3. `annotate.ts`：曲率限速、路段名（与下方地面道路匹配）、出入口识别并与 `scripts/data/exits.json`
   中的出口编号对齐、标志与测速点布设。
4. `city.ts` / `terrain.ts`：建筑高度估算与程序化补全、珠江水面（泛洪填充 + 等值线）、绿地、树木、地形。

## 目录

```
scripts/          数据管线（Overpass 下载、路网/高程/标志/城市生成）
public/data/      生成的路网与城市数据（ODbL）
public/assets/    CC0 纹理
src/road/         路网运行时与道路/高架几何、桥面净空查询（防穿模）
src/vehicle/      车辆动力学、道路跟踪与碰撞、车与车接触、程序化车模
src/traffic/      AI 车流
src/race/         竞速模式：比赛流程、AI 车手、起终点线
src/world/        城市、地标、标志（及其支撑布置）、天空与材质
src/game/         行程、规则与违章
src/ui/           HUD、小地图、菜单、触屏
src/audio/        合成音效
tests/            Vitest 测试（整圈自动驾驶、匝道车流、竞速、防穿模校验、车牌朝向）
e2e/              Playwright 浏览器冒烟测试（自由驾驶与竞速模式）
.github/          GitHub Pages 自动部署工作流
```
